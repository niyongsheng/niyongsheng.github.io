### Quick Start

```bash
npm install          # 安装依赖
npm run server       # 本地预览 → http://localhost:4000
npm run build        # 生成静态文件到 public/
npm run deploy       # 部署到 GitHub Pages
```
> [!TIP]  
> 部署由 [GitHub Actions](.github/workflows) 自动完成。
